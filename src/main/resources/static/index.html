About this build

Written in plain Java against the JDK. The HTTP server, router, filter chain, dependency-injection container, JSON codec, session store and connection pool are all hand-written — no Spring, Hibernate, Thymeleaf, React or Bootstrap. The only external artifacts are the MySQL JDBC driver and JUnit, and JUnit is test-scope only.
